# Theming

`@kenshinx/ui` uses CSS variables as its theme contract. The Tailwind preset maps semantic utilities to those variables, so token overrides cascade through the full library.

For maintainers, the canonical theme spec lives in `docs/maintainers/design-system.md` in the repository.

## How It Works

The library ships with:

1. `@kenshinx/ui/styles.css` for token definitions
2. `@kenshinx/ui/tailwind-preset` for semantic Tailwind mappings

Use both together:

```ts
import "@kenshinx/ui/styles.css";
import kenshinPreset from "@kenshinx/ui/tailwind-preset";
```

## Default Theme Shape

```css
:root {
  --background: 0 0% 100%;
  --foreground: 240 10% 3.9%;
  --primary: 240 5.9% 10%;
  --primary-foreground: 0 0% 98%;
  --radius: 0.5rem;
}

.dark {
  --background: 240 10% 3.9%;
  --foreground: 0 0% 98%;
  --primary: 0 0% 98%;
  --primary-foreground: 240 5.9% 10%;
}
```

## Override Tokens

```css
@import "@kenshinx/ui/styles.css";

:root {
  --primary: 221 83% 53%;
  --primary-foreground: 210 40% 98%;
  --accent: 199 89% 48%;
  --accent-foreground: 210 40% 98%;
  --radius: 0.75rem;
}

.dark {
  --primary: 217 91% 60%;
  --primary-foreground: 222 47% 11%;
}
```

## Core Tokens

### Colors

| Token | Purpose |
|-------|---------|
| `--background` | App background |
| `--foreground` | Default text color |
| `--primary` | Primary actions and emphasis |
| `--primary-foreground` | Text on primary surfaces |
| `--secondary` | Secondary surfaces |
| `--secondary-foreground` | Text on secondary surfaces |
| `--muted` | Subtle backgrounds |
| `--muted-foreground` | Secondary text |
| `--accent` | Highlight color |
| `--accent-foreground` | Text on accent surfaces |
| `--destructive` | Error and destructive actions |
| `--destructive-foreground` | Text on destructive surfaces |
| `--border` | Default borders |
| `--input` | Input borders |
| `--ring` | Focus rings |

### Other Tokens

| Token | Purpose |
|-------|---------|
| `--radius` | Base border radius |
| `--chart-1` to `--chart-5` | Chart color scale |

## Radius Mapping

The preset derives radius utilities from `--radius`:

- `rounded-lg` -> `var(--radius)`
- `rounded-md` -> `calc(var(--radius) - 2px)`
- `rounded-sm` -> `calc(var(--radius) - 4px)`

## Dark Mode

Dark mode is class-based. Toggle the `dark` class on the root element used by your app.

```ts
document.documentElement.classList.toggle("dark");
```
